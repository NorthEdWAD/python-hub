# Unit 01: HTML & CSS Basics

## Overview
This unit introduces students to the foundational concepts of HTML and CSS. By the end of the unit, students will be able to create and style simple web pages using semantic HTML and basic CSS.


## How to Use This Unit  

- Move through the lessons in order
- Complete the projects to apply what you've learned

---

## Learning Objectives
By completing this unit, students will:
- Understand the structure of an HTML document.
- Use semantic HTML elements to create accessible web pages.
- Apply basic CSS to style text, colors, and layouts.
- Build a simple multi-page website.
