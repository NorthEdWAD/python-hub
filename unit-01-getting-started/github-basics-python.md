**Project Overview:** In this activity, you will create a simple project folder and sync it with GitHub. This is how professional web developers save their work and make it available to the other members of their coding team.  

**Objectives:**
* Students will create a local project folder and turn it into a GitHub repository.
* Students will write basic HTML and CSS to create practice files.
* Students will use GitHub Desktop to **commit** and **push** the changes they make to their files to a GitHub repository.

**Technical Requirements:**
* Required HTML elements: `<!DOCTYPE html>`, `<html>`, `<head>`, `<title>`, `<body>`, `<h1>`, `<p>`
* Required CSS properties: `background-color`, `color`
* Google Chrome or Mozilla Firefox

---

**Step-by-Step Instructions:**

1. **Create your project folder:** Create a new folder on your computer named `github-practice`. Inside this folder, create two new files: `index.html` and `styles.css`.
2. **Add basic HTML:** Open `index.html` and add a standard HTML5 boilerplate. Inside the `<body>`, add an `<h1>` that says "My First GitHub Repo."
3. **Connect your CSS:** In your `<head>`, link your `styles.css` file. Then, open `styles.css` and give the `body` a background color so you can see that it's working.
4. **Check your work:** Open `index.html` in your browser. If you see your heading and your background color, you are ready to move to GitHub!
5. **Open GitHub Desktop:** Open the GitHub Desktop app and select **"Create a New Repository on your hard drive."** Name it `github-practice` and make sure the "Local Path" is the same folder you just created.
6. **The First "Commit":** Look at the bottom-left of GitHub Desktop. In the "Summary" box, type "Initial Commit." Click the blue **Commit to main** button. This saves a "snapshot" of your work.
7. **Publish to the Web:** Click the **Publish repository** button at the top. Uncheck the box that says "Keep this code private" so your teacher can see it, and click **Publish**.
8. **Check your work:** Log in to GitHub.com in your browser and check your "Repositories." You should see your project files living online!
9. **Make a Change:** Go back to your code and change the color of your `<h1>` text. Save the file. 
10. **Push the Update:** Return to GitHub Desktop. You’ll see your change highlighted. Type "Changed heading color" in the summary, click **Commit**, and then click **Push origin** to send the change to the web.

---

**Submitting Your Work:**  
* Make sure your `github-practice` folder contains both `index.html` and `styles.css`.
* Upload all project files to a new GitHub repository named `github-practice`.

**Assessment:** 
You will be graded on:
- whether your repository is public
- if your files are named correctly
- if your GitHub commit history shows that you successfully updated your code
