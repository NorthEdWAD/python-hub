This project is designed to give students a quick, hands-on introduction to version control using GitHub Desktop. By the end of this activity, students will have a live repository containing their first web files.

---

**Project Overview:** In this activity, students will learn the fundamental workflow of Git and GitHub by creating a local project and publishing it to the cloud. [cite_start]They will use GitHub Desktop to manage their files, commit changes, and push their work to a remote repository[cite: 13, 82].

**Learning Objectives:**
* [cite_start]Students will be able to create a local project folder and initialize it as a GitHub repository[cite: 20, 82].
* [cite_start]Students will be able to author basic HTML and CSS files to serve as project assets[cite: 6, 7].
* [cite_start]Students will be able to perform "Commit" and "Push" operations to sync local changes with GitHub[cite: 13, 82].
* [cite_start]Students will be able to verify their uploaded content on the GitHub web interface[cite: 13, 14].

**Skill Level:** Beginner

[cite_start]**Estimated Time:** Project will take 1 class session (approx. 30 minutes) to complete [cite: 2]

**Technical Requirements:**
* [cite_start]**Required HTML elements:** `<!DOCTYPE html>`, `<html>`, `<head>`, `<title>`, `<body>`, `<h1>`, `<p>` [cite: 16]
* [cite_start]**Required CSS properties:** `background-color`, `color`, `text-align` [cite: 17, 44, 47]
* [cite_start]**Software:** GitHub Desktop, a code editor (e.g., VS Code), and a GitHub account[cite: 13, 18, 82].

---

### **Step-by-Step Instructions:**

1.  [cite_start]**Set up your local folder:** Create a new folder on your computer named `github-practice`[cite: 20].
2.  **Initialize the Repository:** Open GitHub Desktop. [cite_start]Select "File" > "Add Local Repository" (or "Create New Repository") and point it to your `github-practice` folder[cite: 82].
3.  **Create your HTML file:** Inside your folder, create a file named `index.html`. [cite_start]Add a basic HTML5 structure with a heading that says "My GitHub Test"[cite: 21, 22, 34].
4.  **Create your CSS file:** Create a file named `style.css`. [cite_start]Add a rule to change the `background-color` of the body to any color you like[cite: 21, 40, 44].
    > **Check your work:** Open `index.html` in a browser. Does your background color appear? [cite_start]Is your heading visible? [cite: 55]
5.  [cite_start]**Link the files:** In the `<head>` of your `index.html`, add the `<link>` tag to connect your `style.css`[cite: 24, 31].
6.  **View changes in GitHub Desktop:** Open the GitHub Desktop app. [cite_start]You should see your new files listed in the "Changes" tab on the left[cite: 13].
7.  **Craft your first commit:** In the "Summary" box at the bottom left, type "Initial commit." [cite_start]Click the blue **Commit to main** button[cite: 82].
8.  **Publish to GitHub:** Click the **Publish repository** button at the top. [cite_start]Ensure "Keep this code private" is unchecked if you want others to see it, then click **Publish**[cite: 82, 83].
    > **Check your work:** Log into GitHub.com in your browser. [cite_start]Look at your profile—do you see the `github-practice` repository listed? [cite: 13, 14]
9.  **Make a change:** Go back to `style.css` and change the text color of your `<h1>`. [cite_start]Save the file[cite: 46, 47].
10. **Push the update:** Return to GitHub Desktop. You will see the change. [cite_start]Enter a summary like "Updated heading color," click **Commit**, and then click **Push origin**[cite: 13, 75, 82].
