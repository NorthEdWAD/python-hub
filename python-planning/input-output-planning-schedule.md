## Essentialist Python Input and Output Unit Planning Schedule

**Unit:** Python Input and Output
**Key Learning Goals:**
- Understand how to use the `input()` function to get user input
- Learn how to use the `print()` function to display output
- Use input and output to create interactive programs
- Apply input and output in simple programs to solve real-world problems

---

### Monday: Focus on What Matters
- **First 25 minutes:** Identify the 3–4 key learning goals for the Python Input and Output unit.
- **Next 25 minutes:** Plan one main activity for each goal (e.g., a hands-on exercise using `input()` and `print()`).
- **Last 10 minutes:** Remove any extra materials or examples that don’t directly support these goals.

---

### Tuesday: Build the Lesson
- **First 25 minutes:** Write lesson steps that focus only on the key ideas about input and output.
- **Next 25 minutes:** Design one hands-on activity, such as a simple program where students create an interactive mad-libs game.
- **Last 10 minutes:** Review the lesson for clarity and simplicity.

---
### Wednesday: Gather the Best Resources
- **First 25 minutes:** Find one high-quality tutorial or video that explains Python input and output clearly.
- **Next 25 minutes:** Create simple starter code that demonstrates how to use `input()` and `print()`.
- **Last 10 minutes:** Test the starter code to ensure it is clear and works as intended.

---
### Thursday: Test Understanding
- **First 25 minutes:** Create one short assessment, such as a quiz or coding exercise, to check if students understand how to use input and output.
- **Next 25 minutes:** Make a simple rubric with clear criteria (e.g., correct use of `input()` and `print()`, proper interaction with the user).
- **Last 10 minutes:** Confirm that the assessment effectively tests the key goals about input and output.

---
### Friday: Final Touches
- **First 25 minutes:** Organize all materials (e.g., lesson notes, starter code, assessment) so students can easily access them.
- **Next 25 minutes:** Remove any unnecessary or redundant materials.
- **Last 10 minutes:** Save and prepare everything for delivery to the class.
