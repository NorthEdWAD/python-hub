## Essentialist Python Variables Unit Planning Schedule

**Unit:** Python Variables
**Key Learning Goals:**
- Understand what variables are and why they are used in programming
- Learn how to create, assign, and update variables in Python
- Use variables to store and manipulate different data types (e.g., integers, strings, floats)
- Apply variables in simple programs to solve real-world problems

---

### Monday: Focus on What Matters
- **First 25 minutes:** Identify the 3–4 key learning goals for the Python Variables unit.
- **Next 25 minutes:** Plan one main activity for each goal (e.g., a hands-on variable assignment exercise).
- **Last 10 minutes:** Remove any extra materials or examples that don’t directly support these goals.

---

### Tuesday: Build the Lesson
- **First 25 minutes:** Write lesson steps that focus only on the key ideas about variables.

- **Last 10 minutes:** Review the lesson for clarity and simplicity.

### Thursday: Test Understanding
