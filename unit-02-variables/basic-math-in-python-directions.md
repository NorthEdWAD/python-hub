# Unit 02: Variables & Simple Data Types
## Basic Math in Python

---

### 🎯 The Objective
*By the end of this lesson, you will be able to:*
* define and use constants and variables to do basic math in Python
* use an f-string to display output (the answers)

---

### 🚀 Starter Code  

- Download the `basic-math-starter.py` script from GitHub into a NEW folder (`basic-math`) on your laptop
- Open the `basic-math` folder in VS Code

### ✅ Success Criteria

Your project is complete when you've:  

1. used variables to set up and to do the designated math problems
2. used an `f-string` to display your results (output)
3. updated the comment block at the top of your script with your info

> **NOTE:** Focus on mastering these three things. Quality over quantity!
