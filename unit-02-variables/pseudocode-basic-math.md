# Python: Getting Input from the User, Doing Math, and Displaying Output

**What is Pseudocode?**  
Think of pseudocode as the sketch of your script.  

When an artist draws a picture, they usually start with a rough pencil sketch before they bring out the paint.   

Pseudocode is your rough sketch! It is a way to write down the steps of your script in plain English, without worrying about exact Python rules for writing code. It helps you plan out your Python script before you start typing any code.

---

### Example:

**Python Code:**

```python
num1 = 5
num2 = 10
total = num1 + num2
print(f"The total is {total}.")
```

**Pseudocode:**

```text
Set num1 to 5.
Set num2 to 10.
Add num1 and num2, store the result in total.
Display "The total is " followed by the total.

```
