# Pseudocode Activity: Calculating the Area of a Right Triangle

**What is Pseudocode?**
Pseudocode is a way to write down the steps of a program in plain English, without worrying about the exact syntax of a programming language. It helps you plan your code before writing it.

---

### Example:
**Python Code:**
```python
num1 = 5
num2 = 10
num3 = 15
total = num1 + num2 + num3
average = total / 3
print(average)
```

**Pseudocode:**
```
Set num1 to 5
Set num2 to 10
Set num3 to 15
Add num1, num2, and num3, store the result in total
Divide total by 3, store the result in average
Print average
```
